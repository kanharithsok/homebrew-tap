# Homebrew Tap

Homebrew casks for [kanharithsok](https://github.com/kanharithsok)'s apps.

## Install

```bash
brew tap kanharithsok/tap
brew trust kanharithsok/tap
brew install --cask stock-peek
brew install --cask focusbar
```

Homebrew 7 requires third-party taps to be trusted before installing.

## Available casks

| Cask | App | Description |
| --- | --- | --- |
| `focusbar` | FocusBar | Menu-bar focus sessions with best-effort distraction blocking |
| `stock-peek` | Stock Peek | Lightweight stock quotes in the macOS menu bar |
