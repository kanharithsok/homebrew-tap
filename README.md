# Homebrew Tap

Homebrew casks for [kanharithsok](https://github.com/kanharithsok)'s apps.

## Install

```bash
brew install --cask kanharithsok/tap/stock-peek
```

## Available casks

| Cask | App | Description |
| --- | --- | --- |
| `stock-peek` | MacStockWidget | Lightweight stock quotes in the macOS menu bar |
